# Goal

Based on the design document, break down functional tasks.

---

# Input

Please read:

- `docs/features/{feature-name}.md`
- `docs/design/{feature-name}-design.md`

---

# Output

Please generate:

`tasks/{feature-name}/`

Each task file must be independently completable, testable, small-grained, with acceptance criteria.

Also generate:

- `tasks/{feature-name}/README.md`
- `tasks/{feature-name}/progress.md`
- `tasks/{feature-name}/checklist.md`

Do not begin implementation in this step.
