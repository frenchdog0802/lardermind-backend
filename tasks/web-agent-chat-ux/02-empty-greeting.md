# 02 — Empty greeting density (P0)

## Goal

Make Chat empty state read as a single agent greeting, not a stacked lifestyle hero.

## Acceptance

- [ ] Named user: one headline via `ai.greetingHi` (no second period line)
- [ ] Unnamed: period greeting only (`ai.greetingMorning|Afternoon|Evening`)
- [ ] Remove `ai.welcome` helper from empty state when suggestion cards are shown
- [ ] Tighten vertical spacing (no large `mb-8` dead zones between blocks)
- [ ] Still centered in transcript pane; Warm Kitchen `font-display` for headline only
